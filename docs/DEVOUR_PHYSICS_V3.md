# Legend Devouring Physics v3 — Implementation Contract

## Architecture
- GitHub **Home** is the durable template source, verifier and auto-merge gate.
- Hugging Face is a metadata discovery catalogue of teacher models. Legend does not download teacher weights.
- A Child API is the execution, conduct, extraction and proposal worker.
- RevelaAI attempts verified Legend templates first; an unknown result falls through to the existing Gemini/provider chain.
- Gemini is the initial teacher. When a successful Gemini text response returns, RevelaAI may request a method-only T-Lang candidate and submit it to the Child's import endpoint. The learning request is opt-in via `LEGEND_LEARNING_ENABLED`, requires configured child API credentials, and returns its outcome in chat telemetry.

## Child endpoints
- `GET /v1/devour/catalog?modality=image&limit=100`: metadata-only list.
- `POST /v1/devour/discover`: authenticated bounded catalogue discovery; body `{modality?, limit?}`.
- `POST /v1/devour/conduct`: authenticated conduct prompt for the selected modality/task.
- `POST /v1/devour/import`: authenticated import of a Gemini-produced candidate; candidate is validated and each declared test executes before Home submission.
- `POST /v1/devour/learn`: configured OpenAI-compatible teacher endpoint produces and verifies a candidate from a supplied lesson. Requires child/admin credentials.
- `GET /v1/devour/stats`: catalog count (bounded view), verified/rejected learning counters and template count.
- `POST /legend/generate`: RevelaAI verified-first composition API; `verified:false` means fallback should be used.

## Modality taxonomy
image, audio/speech, video, music, code, multilingual, text. Discovery is metadata only and bounded per category. Discovery is not teaching and not learning.

## Learning and acceptance
A method is not devoured merely because a teacher describes it. A candidate must:
1. be representable by T-Lang v1's allowlisted deterministic operations;
2. have a valid schema and typed inputs;
3. include at least two test vectors;
4. execute each test successfully;
5. pass Home's separate verifier and proposal workflow.

External tool adapters for image pixels, audio generation/transcription, video rendering, and music synthesis are not yet executable T-Lang operations. These modalities can be catalogued and conduct prompts prepared; no output asset is claimed to have been generated by Legend until a registered provider adapter and artifact verification are implemented and tested. Current image/audio/video models listed in the HF catalogue are not automatically callable: HF model listing does not grant inference access.

## RevelaAI environment
Configure the RevelaAI Render service server-side:
- `LEGEND_API_BASE`: deployed child API origin (no trailing slash).
- `LEGEND_CHILD_ID`: must exactly match the child service's `LEGEND_CHILD_ID`.
- `LEGEND_API_KEY`: must match that child's `LEGEND_CHILD_API_KEY`.
- `LEGEND_LEARNING_ENABLED=true`: enable method extraction after Gemini text fallback. Disable to stop teacher method capture.

Do not put these values in Vite/frontend config. The first request may cold-start a free Render child; the Legend client uses a short timeout and fails open to the existing provider pipeline.

## Usage measurement
Track verified template hits, unknown/fallback calls, learning accept/reject outcomes and external tool usage. Do not report Gemini's share declining without real telemetry over a defined denominator/time window. A goal of 20% then 5% then 0% is an aspiration, not a guaranteed curve.

## Multimodal reality
Legend can only independently execute what is implemented as a verified procedure or registered tool adapter. Text/multilingual/math/code methods can become symbolic where they are deterministic. Image/audio/video/music require actual provider adapters and artifact-level checks (e.g. valid image dimensions/pixels, playable audio stream, video decode and temporal checks). A compact T-Lang method description alone does not produce media.
