# Legend Research Roadmap

## Milestone 0.1 — deterministic core

- 20 seed T-Lang procedures.
- Restricted interpreter and deterministic verifier.
- Child-local learning workspace.
- Optional external teacher adapter.
- Signed GitHub child submissions and Home admission workflow.
- API and Docker runtime.
- Explicit UNKNOWN policy.

## Milestone 0.2 — measurable composition

- Multi-step composition with typed intermediate values.
- Property-based and fuzz testing for every operator.
- Stronger duplicate detection based on normalized program graphs.
- Library version manifests and deterministic child sync.
- Home-side persistent child reputation and automated circuit breaking.
- Reproducible benchmark suite for cost, latency, correctness, and coverage.

## Milestone 0.3 — modality adapters

- Vision extraction adapter with dataset and consent controls.
- Audio transcription/feature adapter.
- Code analysis adapter with sandboxed, non-executing static inspection.
- Separate evidence record for every modality-derived procedure.
- No claim that symbolic templates replace perception models.

## Research questions

1. How many recurring tasks can be represented by the operator vocabulary?
2. What is the false-accept rate of the verifier on adversarial proposals?
3. How often does an admitted procedure fail on held-out inputs?
4. How many teacher calls are avoided through reuse?
5. What storage and synchronization cost is incurred per useful procedure?
6. Which task classes remain outside the symbolic system's capability?

A larger template count is not an intelligence metric. Quality, generalization, calibrated abstention, provenance, and measured task coverage are the relevant metrics.
